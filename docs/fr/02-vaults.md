# 2. Vaults et collatéral

Les vaults encadrent les dépôts, emprunts et ratios de collatéral. La dette et les intérêts sont mis à jour selon les paramètres du marché et les index internes.

Ce chapitre relie le mécanisme au parcours d’exécution et signale les invariants que l’intégrateur doit préserver.
