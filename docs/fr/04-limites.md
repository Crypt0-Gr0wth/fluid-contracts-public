# 4. Limites et intégration

Les intégrateurs doivent vérifier les autorisations, les oracles, les index et les arrondis. Documentation בלבד : aucune installation, compilation, exécution ou validation de test.

Ce chapitre relie le mécanisme au parcours d’exécution et signale les invariants que l’intégrateur doit préserver.
